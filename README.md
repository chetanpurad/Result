# Student Marks Calculator — Debugging Lab

## Objective
Find and fix the bugs in this Python program.

## Program requirements
1. Ask for the student's name and marks in three subjects.
2. Calculate the total and average correctly.
3. A student passes only if they score at least 35 in every subject.
4. Assign the grade based on the average:
   - A: 80 or above
   - B: 60 to less than 80
   - C: 40 to less than 60
   - D: below 40

## Your tasks
1. Run the program and try different marks.
2. Identify the errors and correct the program.
3. Test it with at least three different sets of marks.
4. Commit your changes and push your fix to your branch.
5. Open a Pull Request to the teacher's repository.

Do not edit the teacher's original repository directly.
